# StreamFree — Licensing Response Tracker

**Purpose:** practical tracking of licensing outreach status per provider. As of this
document's creation, **no provider has been contacted** — every entry below is a template
ready to be filled in once outreach begins. Update this file as conversations progress;
do not mark any field as confirmed unless the provider has actually stated it.

**Status values to use:**
`Not Contacted` · `Contacted` · `Awaiting Response` · `Follow Up` · `Terms Received` · `Legal Review` · `Approved` · `Not Suitable`

**Reminder:** confirming "AVOD" does not confirm "rewarded ads" or "web rights" — track
these as separate fields/answers, never inferred from each other.
